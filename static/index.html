Mathematical Formulation & Algorithmic Metrics

Core equations executed by FailureDetector, PropagationAnalyzer, RootCauseEngine, and AdaptiveOptimizer.

1. LLM-as-a-Judge Fault Detection FailureDetector
Fault(s_i) = I( JudgeScore(s_i) < τ ), τ = 0.70
Step 'extraction': 0.32 < 0.70 → FAULT
Each span is scored in [0, 1] for factual grounding and constraint adherence. Any span below τ = 0.70 triggers classification.
2. Causal Propagation Score (PS) PropagationAnalyzer
PS(i→j) = (1 - S_i) × (1 - S_j) × W_dep
Overall PS = 0.33 (2 downstream spans)
Quantifies how strongly an upstream error at span i degrades downstream dependent spans j across the DAG.
3. Root-Cause Confidence (RCC) RootCauseEngine
RCC = α·Depth + β·Severity + γ·Cascade
RCC = 88% (Step 2: extraction)
Ranks candidate failing spans by topological earliness (α), score drop magnitude (β), and downstream blast radius (γ).
4. Closed-Loop Quality Gain (ΔQ) AdaptiveOptimizer
ΔQ = Score_healed - Score_baseline
0.41 → 0.94 (ΔQ = +0.53)
Mutates temperature (→ 0.0) and injects a grounding guardrail at the root-cause span, then re-evaluates the full pipeline.
